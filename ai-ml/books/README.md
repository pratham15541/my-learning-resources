## Book Notes

### Foundations & Applied ML

- [Mathematics for Machine Learning](mathematics-for-ml-book.pdf): A solid foundation in linear algebra, analytic geometry, matrix decompositions, vector calculus, probability, and optimization required for ML.
- [Python Machine Learning by Example](python-machine-learning-by-example-3.pdf): Practical introduction to ML algorithms using Python, with hands-on projects and example-driven learning.
- [Hands-On Machine Learning with Scikit-Learn, Keras, and TensorFlow](Hands-On_Machine_Learning_with_Scikit-Learn_Keras_and_TensorFlow_3rd_Edition_-_Aurelien_Geron.pdf): The definitive practical guide to classic machine learning and deep learning using industry-standard libraries.

### Deep Learning & Specialized Architectures

- [Deep Learning](Deep%2BLearning%2BIan%2BGoodfellow.pdf): The classic theoretical reference covering deep networks, optimization, regularization, convolutional networks, and generative modeling.
- [Hands-On Graph Neural Networks Using Python](HandsOnGraphNeuralNetworksUsingPython.pdf): Practical guidance on graph representations, GCNs, GraphSAGE, and applying neural networks to graph data.
- [Reinforcement Learning: An Introduction](SuttonBartoIPRLBook2ndEd.pdf): The seminal introduction to reinforcement learning, dynamic programming, temporal-difference learning, and function approximation.

### Natural Language Processing & Large Language Models (LLMs)

- [Natural Language Processing with Transformers](<Natural%20Language%20Processing%20with%20Transformers%20Building%20Language%20Applications%20with%20Hugging%20Face%20by%20Lewis%20Tunstall%20%20Leandro%20von%20Werra%20%20Thomas%20Wolf.pdf>): Building language applications using the Hugging Face ecosystem, transfer learning, and transformer architectures.
- [Hands-On Large Language Models](Hands-On_Large_Language_Models_-_Jay_Alammar.pdf): Visual and conceptual guide to understanding, using, and adapting large language models.
- [Building LLMs for Production](Building%20LLMS%20for%20production.pdf): Operational guide to building, evaluating, and scaling LLM applications in real-world production environments.

### Data Engineering & ML System Design

- [Fundamentals of Data Engineering](<Fundamentals%20of%20Data%20Engineering%20(Reis,%20JoeHousley,%20Matt)%20(Z-Library).pdf>): Core concepts of data engineering lifecycle, data storage, ingestion, processing, and serving.
- [Designing Machine Learning Systems](Designing%20Machine%20Learning%20Systems.pdf): Frameworks and methodologies for training, deploying, monitoring, and maintaining production-ready ML systems.
- [AI Engineering: Building Applications With Foundation Models](<AI%20Engineering_%20Building%20Applications%20With%20Foundation%20Models%20by%20Chip%20Huyen%20(1).pdf>): Practical guide on working with LLMs, prompt engineering, RAG, agentic systems, and application deployment.
- [Generative AI System Design Interview](generative-ai-system-design-interview.pdf): Advanced architecture guide for building scalable generative AI systems, focusing on tradeoffs, evaluation, and system interview questions.
